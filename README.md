# BMW 420i 컨버터블 가격 비교

실제 공개 광고의 가격·모델연도·최초등록·주행거리·색상·판매조건을 표로 비교하는 사이트와 일반 Python 수집 프로그램입니다. LLM/API 토큰, 판매자 연락, 외부 유료 API를 사용하지 않습니다.

## 실행

Python 3.11 이상:

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m playwright install --with-deps --only-shell chromium
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m collector.run
.venv/bin/python -m collector.validate
python -m http.server 4173 --directory dist
```

`.github/workflows/daily-collection.yml`은 매일 Asia/Seoul 08:00 (UTC 23:00)에 GitHub의 표준 Linux 실행기로 수집합니다. 수동 실행도 가능합니다. GitHub 예약은 부하에 따라 지연되거나 실행이 누락될 수 있습니다. 화면에 마지막 관측 시각과 36시간 경과 표시가 있습니다. AI 호출이나 매일 에이전트 실행은 없습니다.

사이트의 `dist/data-source.json`에 설정한 공개 데이터 URL을 먼저 확인하고, 접근 실패하면 사이트에 포함된 마지막 정상 스냅샷을 사용합니다. 공개 배포에는 `dist/`만 사용합니다. 수집 프로그램은 예약 실행 환경에서 실행되며 사이트 방문자가 실행하지 않습니다.

## 현재 자동 판독 범위

- 엔카: Playwright Chromium headless로 실제 검색 UI의 BMW → 4시리즈 → 가솔린 → 420i 컨버터블 등급을 선택하고 페이지를 이동합니다. 쿠페/다른 엔진을 제외하고 광고 카드와 일반 표를 모두 판독합니다. 검색 목록 후보는 상세 검증과 분리합니다. 현재 상세 경로는 robots.txt에서 제한하므로 자동 접근하지 않으며 이전 상세 자료를 보존합니다. `--no-browser`로 브라우저 수집을 끌 수 있습니다.
- KB차차차: 실제 BMW → 4시리즈 → 420i Convertible 등급 검색, 공개 상세 기본정보·진단·보험 건수·용도/소유자 이력·보증 표시를 판독합니다. 보험 수리금액·세부 내역은 로그인 영역으로 남깁니다. 보안 확인 안내를 만나면 해당 출처의 후속 요청을 중단합니다.
- 보배드림 수입차/사이버매장, 동성모터스 BPS: 헤드리스 화면과 공개 HTML 페이지 탐색을 함께 사용합니다. 컨버터블 등급, 리스 조건과 명시적인 판매완료를 구분합니다.
- 코오롱 702: 실제 BMW → 4시리즈 검색과 상세 공개 보험·점검·보증 요약을 판독합니다. 이전등록 예상비용은 광고가격과 분리합니다.
- 차란차: 동적 BMW 4시리즈 목록과 추가 로딩을 확인합니다. 상세 경로는 robots 제한이 있어 목록 후보로만 보존합니다. 케이카도 실제 키워드 검색을 사용하며 상세 경로 제한 시 후보와 원문 링크만 남깁니다.
- 다나와 중고차·엠파크: 실제 제휴 목록에서 원 판매처로 연결해 상세를 판독하고, 확인된 동일 차량은 합칩니다. 엠파크 자체 검색 로딩 실패를 매물 0건으로 처리하지 않습니다.
- 리본카·오토인사이드·헤이딜러·T car·오토허브·당근: 사이트별 실제 공개 검색 UI를 사용합니다. 정상 로딩과 검색 결과 없음이 명시된 경우만 0건으로 기록합니다. 판매준비차량이나 당근의 지역 제한은 전국 재고와 구분합니다.
- BMW 통합 BPS·바바리안·오토벨·첫차·공식 딜러 안내: 브라우저 렌더링과 접근 정책을 확인합니다. 로딩 오류·접근 차단·안내 페이지 확인을 재고 검색 완료로 표시하지 않습니다.
- 다나와 신차: 컨버터블 가솔린 2.0 가격표를 펼쳐 P1/P2/P2-0별 가격과 적용 시작일을 판독합니다. 플랫폼 가격표는 공식가 확인 또는 당월 프로모션과 구분합니다.
- 겟차: 지정된 공개 모의견적의 기준월과 가격표. BMW 코리아는 공식 PDF 탐색, BMW 샵은 접근 정책을 확인하며 확인하지 못한 가격·흰색 재고는 생성하지 않습니다.
- 공개 웹 검색은 허용된 RSS 경로에서만 자동 시도합니다. 검색엔진 제한 시 `접근 차단`을 기록합니다. 이번 조사에서는 별도 공개 웹 검색도 병행했으며, 검색 요약만 확인한 차량을 상세 검증 자료에 넣지 않았습니다.

**모든 사이트의 재고를 빠짐없이 수집하는 상태는 아닙니다.** 출처마다 전체 탐색 여부와 마지막 정상 시각을 공개합니다. 표준 Chromium을 사용하며 로그인·CAPTCHA·robots 제한을 우회하지 않습니다. 검색 UI가 바뀌거나 조회가 실패하면 이전 자료와 정상 확인 시각을 보존합니다. 브라우저 상세는 출처당 최대 60개, 목록은 기본 15페이지와 실행시간 제한 안에서 탐색합니다. 원본 HTML은 무시되는 로컬 캐시에만 저장하고 공개하지 않습니다.

## 비교 화면과 AI 요약

첫 화면은 그래프 보기입니다. 가격·모델연도·주행거리는 빠른 범위 버튼으로 고르고 색상·지역·세부 조건은 패널에서 선택합니다. 기본 범위는 모두 무제한이며, 표 보기는 오름차순/내림차순 정렬을 지원합니다. 모바일에는 하단 필터 패널과 선택 차량 요약을 제공합니다. 그래프는 가격 대 주행거리/연식, 연식별 관측 범위와 사고·보험 근거 분류를 보여줍니다. 미확인 가격과 금융·리스 금액은 일반 차량가격 그래프에서 제외합니다.

`dist/ai-summary.json`은 작성 시점이 표시된 AI 검토 메모입니다. 가격대별 후보와 대안의 근거를 저장하고, 비교 근거가 바뀌면 추천 문구를 숨깁니다. 매일 수집기가 AI를 호출하거나 이 메모를 자동으로 다시 작성하지는 않습니다.

검색 목록은 별도 표에서 광고가격·최초등록·주행거리 정렬과 지역 선택을 제공합니다. `listingObservations`는 목록 관측이고 `observations`는 상세 관측입니다. 목록의 최신 가격으로 상세 정상 확인 시각을 덮어쓰지 않습니다. 신규 목록 후보와 실제로 관측된 목록 가격 변경도 별도 이벤트로 남깁니다. 브라우저나 네트워크 오류 시 기존 목록과 시각을 보존합니다.

2026-09-18 검증: 27개 출처를 로컬 headless로 재조회했습니다. KB차차차 29개·코오롱 BPS 1개·엠파크 1개 상세를 확인했고, 엔카 89개·차란차 10개 목록 관측은 상세와 분리했습니다. 다나와 제휴 엠파크 차량은 중복 처리합니다. 정상 광고가 확인된 차량은 중복 제거 후 39대이며 이전 자료도 별도로 보존합니다. 로컬 성공이 클라우드 성공을 뜻하지 않습니다. GitHub 실행 환경에서는 엔카가 비정상 트래픽 접속 제한 안내를 반환했습니다. 이 환경의 일일 엔카 갱신은 현재 성공하지 못하며 이전 자료와 정상 시각을 보존합니다. 제한을 우회하거나 인증을 자동 처리하지 않습니다.

## 가격·기록 규칙

- 월납입금·선수금·보증금·인수금과 차량 전체 광고가격을 구분합니다. 리스 필수 비용이 빠지면 총비용 계산을 하지 않습니다.
- 금융상품 없이 살 수 있는 현금가격은 광고만 보고 확인 처리하지 않습니다. 세금·이전·관리·탁송 비용은 미확인이면 합산하지 않습니다.
- 성능기록 원본과 플랫폼 요약, 판매자 주장은 서로 다른 필드에 기록합니다. 보험 0건은 무사고·무도색 확정이 아닙니다. 루프·누수 상태를 사진으로 판정하지 않습니다.
- `firstSeen`, `lastSuccess`, `checkedAt`을 별도로 유지합니다. 실패 시 가격과 마지막 정상 시각을 바꾸지 않습니다. 삭제/비공개/접근불가를 판매완료로 추정하지 않습니다.
- 같은 차량 식별정보의 해시가 일치할 때만 차량을 묶으며 모든 출처·가격·관측을 유지합니다. 차량번호 원문, 판매자 개인 전화번호와 이메일, 구매자 개인정보는 공개 데이터에 저장하지 않습니다.
- 가격과 판매 상태 이력은 실제 관측 데이터뿐입니다. 첫 수집 전 가격을 만들지 않습니다.

## 파일

- `collector/sources.json`: 지정된 27개 출처 경로 (첫차 두 주소는 하나로, 딜러 안내는 BMW 통합 재고와 분리 계산)
- `collector/parsers.py`: 검증된 사이트별 필드 판독
- `collector/run.py`: 저빈도 HTTP 요청·접근 결과·관측 병합
- `collector/encar_browser.py`: 엔카 동적 검색·목록 관측과 목록 이력 보존
- `collector/browser.py`: 공통 Chromium·robots·보안 확인·시간 제한
- `collector/browser_sources.py`: 다른 출처의 공개 UI 검색과 상세 판독 연결
- `collector/robots.py`: 경로별 최장 일치 robots 정책
- `collector/model.py`: 차량 식별·금액·실패 시 보존·중복 규칙
- `collector/validate.py`: 게시 전 개인정보·모델·가격·시간 검증
- `dist/data.json`: 공개 관측 스냅샷과 이력
- `tests/`: 가격 혼동·차종 혼동·상태 오판을 막는 회귀 검사
